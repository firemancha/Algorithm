### 문제

두 정수 N과 F가 주어진다. 지민이는 정수 N의 가장 뒤 두 자리를 적절히 바꿔서 N을 F로 나누어 떨어지게 만들려고 한다. 만약 가능한 것이 여러 가지이면, 뒤 두 자리를 가능하면 작게 만들려고 한다.

예를 들어, N=275이고, F=5이면, 답은 00이다. 200이 5로 나누어 떨어지기 때문이다. N=1021이고, F=11이면, 정답은 01인데, 1001이 11로 나누어 떨어지기 때문이다.

---

### 입력

첫째 줄에 N, 둘째 줄에 F가 주어진다. N은 100보다 크거나 같고, 2,000,000,000보다 작거나 같은 자연수이다. F는 100보다 작거나 같은 자연수이다.

---

### 출력

첫째 줄에 마지막 두 자리를 모두 출력한다. 한자리이면 앞에 0을 추가해서 두 자리로 만들어야 한다.

---

### 예제 입력

| 예제 입력1                                                  | 예제 출력1 |
| :---------------------------------------------------------- | :--------- |
| 1000<br/>3 | 02 |

| 예제 입력2                                                  | 예제 출력2 |
| :---------------------------------------------------------- | :--------- |
| 2000000000<br/>100 | 00 |

| 예제 입력3                                                  | 예제 출력3 |
| :---------------------------------------------------------- | :--------- |
| 23442<br/>75 | 00 |

| 예제 입력4                                                  | 예제 출력4 |
| :---------------------------------------------------------- | :--------- |
| 428392<br/>17 | 15 |

| 예제 입력5                                                  | 예제 출력5 |
| :---------------------------------------------------------- | :--------- |
| 32442<br/>99 | 72 |

---

### 문제 접근

  - `브루트포스` 문제

  - `N / 100 * 100`으로 마지막 두 자리를 `00`으로 만든 뒤, `0`부터 `i`를 더해가며 `F`로 나누어 떨어지는 첫 번째 `i`를 찾음

    - `0`부터 순회하므로 처음 찾은 값이 가장 작은 두 자리

    - `F ≤ 100`이므로 연속된 `F`개의 수 중에는 반드시 `F`의 배수가 있어서, `00 ~ 99` 안에서 항상 답이 존재함

  - 출력 시 한 자리 수는 앞에 `0`을 붙여 두 자리로 맞춰야 함

    - `C++`: `setw(2) << setfill('0')`

    - `Python`: `format(res, '02')`

  - `N ≤ 2,000,000,000`은 `int` 최댓값(`2,147,483,647`) 이하이므로 `int`로 처리 가능
