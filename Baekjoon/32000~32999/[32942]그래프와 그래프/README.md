### 문제

대곽이는 정보 수업 시간에 그래프를 배운다는 이야기를 듣고 미리 예습해 가기로 하였다. 하지만 대곽이는 그래프 이론이 아닌 좌표평면에서의 그래프를 공부해 버렸다.

대곽이는 $Ax + By = C$라는 방정식으로 주어진 직선의 그래프를 좌표평면에 그렸다. 대곽이는 이 그래프를 정점과 간선으로 이루어진 방향 그래프로 바꾸려고 한다. 정점은 총 
$10$개이며, 각 정점에는 
$1$부터 
$10$까지의 서로 다른 정수 번호가 붙어 있다. 처음에는 그래프에 간선이 존재하지 않는다. 
$1$ 이상 
$10$ 이하인 두 정수 
$x$, 
$y$에 대하여 좌표평면상에서 직선의 그래프가 점 
$(x, y)$를 지난다면 대곽이는 그래프의 
$x$번 정점에서 
$y$번 정점으로 향하는 간선을 정확히 하나 추가한다. <b>그래프에서 시작점과 끝점이 같은 간선도 추가할 수 있다.</b>

대곽이가 위의 과정을 거쳐서 만든 새로운 그래프를 출력해 보자!

---

### 입력

입력의 첫째 줄에 방정식 
$Ax+By=C$의 계수 
$A$, 
$B$, 
$C$가 공백으로 구분되어 주어진다. 
$(-100\, 000 \le A,B,C \le 100\, 000)$ 

 
$A$, 
$B$, 
$C$는 정수이며,  
$A$와 
$B$가 모두 
$0$인 경우는 주어지지 않는다.

---

### 출력

총 
$10$개의 줄을 출력한다. 
$i$번째 줄에는 
$i$번 정점에서 간선을 정확히 
$1$개 지나서 도착할 수 있는 정점들의 번호를 공백으로 구분하여 오름차순으로 출력한다. 만약 그런 정점이 없다면 그 대신 `0`을 출력한다.

### 문제 접근

  - `브루트포스` 문제

  - 제목과 달리 그래프 이론 알고리즘(`BFS`/`DFS` 등)은 필요 없음

    - 정점이 `1 ~ 10`으로 고정되어 있으므로 가능한 점 `(x, y)`는 총 `100`개뿐

  - `i`(`1 ~ 10`), `j`(`1 ~ 10`)를 이중 반복문으로 순회하며 `a * i + b * j == c`이면 `j`를 `i`번 정점의 결과에 추가

    - `j`를 `1`부터 순회하므로 결과는 자동으로 오름차순 정렬됨

  - 해당하는 정점이 없으면 `0`을 출력

  - 최댓값은 `|a * i + b * j| ≤ 2,000,000`이므로 `int` 범위 내에서 오버플로 없음
